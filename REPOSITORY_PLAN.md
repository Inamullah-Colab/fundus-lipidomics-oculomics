# Repository Plan

This folder is prepared as a standalone paper-code repository. A sensible next public setup would be:

1. Create a dedicated GitHub repository with a paper-specific name.
2. Push this local git repository to that remote.
3. Replace the placeholder `repository-code` URL in `CITATION.cff`.
4. Optionally add a permissive license after confirming your preferred terms.
5. Add the final repository URL to the manuscript `Code availability` section.
